TO PUBLISH
1. Go to https://github.com/kaleschulte/kaleschulte.github.io
2. In the Code tab, select Add file > Upload files.
3. Extract this ZIP on your computer first. Upload the files within the extracted folder, not the ZIP itself.
4. Keep the files at the ROOT of the repository (beside index.html).
5. Commit your changes to main. GitHub Pages will republish automatically.
6. Visit https://kaleschulte.com and refresh (Ctrl+F5 if necessary).

PRIVACY: IMPORTANT
Do NOT re-upload an older Word resume with your cell number.
The older file 'Kale_Schulte_Resume.docx' may still be in the repository from an earlier version.
Delete that old file from the public repository if it contains your number.
A normal deletion does not erase prior Git commits; GitHub history cleanup is a separate step.
The V4 website links to resume.html instead of the old Word file.

This package does not change the live GitHub website until you upload and commit it.
